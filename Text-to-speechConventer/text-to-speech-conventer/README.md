# Text To Speech Converter – Mini JS Demo

![Demo GIF](/Text-to-speechConventer/demo.png) 

## Project Overview

This project is a **vanilla JavaScript Text-to-Speech (TTS) application** created as a mini demo for learning purposes.

**Goals of this project:**

- Learn **JavaScript deeply**, including DOM manipulation, events, and Web APIs.  
- Build a **collection of 100 mini projects** step by step to strengthen JS skills.  
- Keep designs **simple, clean, and user-friendly**, focusing on good UX.  
- Prepare for **library/framework learning** after mastering vanilla JS, making a strong foundation for AI-era projects.

This project is fully **inline** with **HTML, CSS, and JS**, making it easy to run anywhere.

---

## Features

- Type any text and **listen to it** using the Web Speech API.  
- **Select different voices** available in the browser.  
- Fully **vanilla JavaScript**, no external frameworks needed.  
- **Single-page design** for easy demos and learning.  
- Clean UX for beginner-friendly experimentation.  

---

## Usage

1. Clone the repository or download the project.  
2. Open `index.html` in a modern browser (Chrome, Edge, or Firefox recommended).  
3. Type any text into the textarea and click the **Listen** button.  
4. Use the dropdown to switch between different voices.
