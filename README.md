# Modern Login Page with Sliding Panel & Local Storage
### Demo

![Login Page Demo](/demo.gif)


A small, interactive **Login / Sign Up page** built to practice **Local Storage** and understand the sliding panel concept. This is my **4th project** in the 100-mini-project series.

## Features

### Sliding Panel
- Smooth **Sign In ↔ Sign Up transitions** within a single container.
- Toggle buttons switch panels with **CSS transitions and transforms**.
- Simple, intuitive flow without overcomplicating the design.

### Local Storage
- Users can **Sign Up** and save their info directly in the browser.
- **Sign In** checks the stored data and validates credentials.
- No backend required—pure frontend implementation.
- Great for learning **how to handle user data on the client side**.

### Interaction Flow
1. Fill in the Sign Up form → data is saved in Local Storage.
2. Switch to Sign In → enter credentials → login validated.
3. Alerts notify success or failure, keeping it simple and clear.

### Tech Stack
- HTML, CSS, Vanilla JavaScript
- Local Storage for storing user data
- CSS transitions & transforms for sliding panel effect
