# 100 Mini Projects – JS, CSS & HTML

Welcome to **100 Mini Projects in JavaScript, CSS, and HTML** by GizzYii.  
This repository is a collection of **small, practical projects** designed to **help you learn vanilla JS deeply**, improve your front-end skills, and build a solid foundation for more advanced frameworks and libraries later.

---

## Goals

- Create **100 mini projects** to gradually master **vanilla JavaScript, CSS, and HTML**.  
- Focus on **learning by doing**, understanding core concepts deeply.  
- Keep designs **simple, clean, and user-friendly**, prioritizing **UX and functionality**.  
- Prepare a **portfolio of projects** to showcase your progress and skills.  
- Lay a strong foundation before moving to **frameworks, libraries, and AI-related projects**.

---

## How to Use This Repository

- Each project is stored in its **own folder**:

- Open `index.html` in a browser to see the project in action.  
- Explore the **code**, **learn from it**, and **modify it** to practice your skills.

---

## Learning Path

- Start with **small projects** to learn **core JS, DOM manipulation, events, and browser APIs**.  
- Move on to **slightly bigger projects** combining HTML, CSS, and JS.  
- After completing enough mini projects, start learning **libraries/frameworks** like React or Vue.  
- Use this collection to **practice coding regularly**, reinforce concepts, and create a strong portfolio.
